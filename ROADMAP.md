# Roadmap

This is a single-maintainer teaching project. The list below is a direction, not
a promise; priorities follow learner value and accessibility.

## Shipped

- [x] Unit 3 companion: ambiguous SSA builder, Law of Cosines SAS/SSS solver,
      surveying practice with animated map solutions.
- [x] Full English ⇄ Thai interface.
- [x] Local progress, badges and JSON export.
- [x] Static CI checks, issue/PR templates and release documentation (1.0.1).

## Next candidates

- [ ] **Keyboard-operable SSA arcs.** Adjust the swing with arrow keys and
      announce the case count, so dragging is not the only direct manipulation.
- [ ] **Scrubbable solution steps.** Let learners step backwards and forwards
      through the map highlight instead of only replaying the animation.
- [ ] **More practice variants.** Angle-side-side inverse cases, area from two
      sides and an included angle, and mixed multi-step problems.
- [ ] **Randomised survey values.** Keep classroom-friendly numbers while varying
      the lake, landmark, ship and drone scenarios.
- [ ] **Printable reference sheet.** A clean black-on-white law summary for
      offline study.
- [ ] **Additional locales.** Keep the Thai glossary stable and extract strings
      only if a third language is genuinely maintained.

## Explicit non-goals

- Accounts, cloud sync, leaderboards or classroom dashboards.
- Server-side grading or analytics.
- Framework migration for its own sake.
- Advertising, tracking or third-party embeds.

## How to influence it

Open a feature request using the template and describe the learner problem, not
only the UI you want. Accessibility fixes and translation corrections are
usually fast-tracked.
